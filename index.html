The philosophy

We built Milky Hotel on the idea that true luxury in the Himalaya is silence, altitude, and a view that does not need improving.

The setting

Dining

The Kailash Table

A nineteen-seat dining room open only for dinner. The menu changes with what came up the mountain that morning — Himalayan trout, foraged nettle, Gundruk fermented greens, and a wine list built around Nepali high-altitude reds.

  • Tasting menu, seven courses
  • Private terrace dinners on request
  • Foraging walks with the head chef
Wellness

A spa built around altitude

Himalayan salt therapy, hot-stone massage with river stone from the Seti Gandaki, and a cedar sauna positioned for the same view as the suites. Sunrise yoga on the lawn is included, sunset gongs are optional.

  • Five treatment rooms, one open-air
  • Daily sunrise yoga on the great lawn
  • Guided acclimatisation walks for trekkers
